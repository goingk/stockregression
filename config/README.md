# 用户配置快照

本目录保存从本机应用数据库导出的自选列表和策略配置，便于通过 Git 备份、比较参数变化和跨机器转移。

- 导出日期：2026-10-20（Asia/Shanghai）。
- `watchlist.json`：自选列表，包含证券代码、显示名称及加入时间；按原加入顺序保存。
- `strategies/*.json`：每份策略一个文件，文件名使用原配置 ID；保存名称、原始策略参数和创建时间。
- 导出数量：12 条自选、3 份策略配置。

这些文件是手动导出的快照。应用仍从应用数据目录中的 `catalog.sqlite` 读取自选和配置，不会自动读取本目录；应用内修改也不会自动更新这些文件。再次同步时需要重新导出并提交 Git。

恢复自选时，使用 `watchlist.json` 的 `items` 中的证券代码和名称，按顺序添加到应用。恢复策略时，使用对应文件中的 `name` 和 `config`；旧版策略参数保留原样，可能需要先通过应用的配置转换功能转换版本。`watchlist.json` 顶层的 `schema_version` 表示快照文件格式，与策略内部的 `schema_version` 分别使用。

这些快照保存个人自选和策略参数；仓库的可见性决定其访问范围。行情数据、数据库、任务历史、结果报告和日志继续保存在本机应用数据目录中。

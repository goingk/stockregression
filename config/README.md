# 用户配置快照

本目录保存从本机应用数据库导出的自选列表和策略配置，便于通过 Git 备份、比较参数变化和跨机器转移。

- 导出日期：2026-10-20（Asia/Shanghai）。
- `watchlist.json`：自选列表，包含证券代码、显示名称及加入时间；按原加入顺序保存。
- `strategies/*.json`：每份策略一个文件，文件名使用原配置 ID；保存名称、原始策略参数和创建时间。
- 导出数量：12 条自选、3 份策略配置。

这些文件是手动导出的快照。正常启动应用时会自动将 `watchlist.json` 中的新增自选导入当前应用数据目录的 `catalog.sqlite`；运行中拉取 Git 更新后，页面读取自选列表时也会自动检查并导入，无需重启。导入按证券代码去重，保留已有证券信息和加入时间，并保留文件之外的本地自选。同一快照不会重复处理；已处理过的条目在本地删除后，不会因重启或快照中其他条目变化而再次添加。条目从快照移除不会删除本地自选；从快照移除后再次加入则视为新增。文件缺失时继续使用本地列表，格式错误时保留本地列表并记录日志。使用代码显式指定独立 `data_dir` 创建的应用实例不导入项目快照。

应用内修改不会自动更新这些文件。要将自选变更带到另一台机器，仍需重新导出 `watchlist.json` 并提交、推送 Git。

自选会按上述规则自动导入；策略配置仍需手动恢复，使用对应文件中的 `name` 和 `config`。旧版策略参数保留原样，可能需要先通过应用的配置转换功能转换版本。`watchlist.json` 顶层的 `schema_version` 表示快照文件格式，与策略内部的 `schema_version` 分别使用。

这些快照保存个人自选和策略参数；仓库的可见性决定其访问范围。行情数据、数据库、任务历史、结果报告和日志继续保存在本机应用数据目录中。

# A 股及 ETF 行情与网格研究台

基于 FastAPI、React、DuckDB、SQLite 和 Parquet 的本地中文研究工作台，支持沪深 A 股及场内 ETF 各周期行情管理、股数网格回测、固定股数定投和参数研究。界面按 1920×1080 桌面设计，并在当前电脑 3120×2080 显示器的 1560×1040 逻辑分辨率下检查；“行情”“数据管理”“策略回测”“参数研究”“结果分析”为独立页面。回测与研究各自保留草稿，通过明确操作传递配置；临时进度显示在右下角，任务历史和结果入口位于顶部任务中心。服务默认只监听 `127.0.0.1`；行情、配置、任务和结果保存在本机。

演示数据带有醒目标识，用于体验界面和检查计算流程。真实行情必须通过同步或导入获得，系统不会用演示数据补齐真实历史缺口。

## 启动

Windows 需要 Python 3.12、`uv`、Node.js 和 npm。直接双击 `start.cmd` 或运行：

```powershell
.\start.ps1
```

启动脚本执行 `uv sync --frozen --python 3.12`，在构建缺失或前端源码、构建配置有更新时执行 `npm ci` 和 `npm run build`，然后启动服务并打开浏览器。默认地址为 <http://127.0.0.1:8000>，API 文档为 <http://127.0.0.1:8000/docs>。

运行后可通过顶栏“重启项目”重新加载后端、依赖和前端构建。确认后服务会受控关闭并由 `restart.ps1` 重新运行标准启动脚本；运行中的任务会被中断，排队任务在服务恢复后继续，启动日志写入 `.local/restart.log`。

手动安装、构建和启动：

```powershell
uv sync --frozen --python 3.12
Push-Location frontend
npm ci
npm run build
Pop-Location
uv run --frozen stockregression serve --open-browser
```

## 首次全市场同步与后续更新

证券目录来自 AKShare 的股票清单、新浪 ETF 清单与数据包已有证券资料。日常任务只更新数据包中已有证券；需要加入新证券时必须使用明确的初始化任务（脚本参数 `-Initialize` 或页面中的显式选项）。目录操作不会自动加入自选，包内证券更新也不会刷新全市场清单。

交付脚本 `sync-market.ps1` 默认更新数据包内已有证券的日线和 1 分钟，下载并发为 2。日线先于 1 分钟执行；5/15/30/60 分钟、周线和月线由本地基础行情按需聚合：

```powershell
# 仅预检范围，不下载行情
.\sync-market.ps1 -DryRun

# 首次全市场日线历史；结束后安装盘后日线与 1 分钟增量计划
.\sync-market.ps1 -Mode history -Frequency 1day -StartDate 2015-01-01 -Initialize -InstallSchedule

# 中断后继续：跳过相同指纹已经完成的标的
.\sync-market.ps1 -Mode history -Frequency 1day -StartDate 2015-01-01 -Initialize

# 更新已有证券的日线和 1 分钟增量
.\sync-market.ps1 -Mode daily

# 只抓取近期 1 分钟窗口；更早历史须先登记数据包或导入文件
.\sync-market.ps1 -Mode repair -Frequency 1min -StartDate 2026-09-28

# 显式执行日线缺口修补
.\sync-market.ps1 -Mode repair -Frequency 1day -StartDate 2026-01-01

# 忽略恢复检查点，重新核对全部目标；内容未变化的记录仍按指纹和时间去重
.\sync-market.ps1 -Mode daily -Fresh
```

预检不会创建行情任务。当前 ETF 数据包保留原有 Parquet 布局并直接作为历史底座；后续新增和修订写入 `.stockregression/increments/`，不重写历史文件。全量替换使用 `snapshot` 模式，旧版本继续可读。原始文件可通过 `data archive` 或数据管理页复制为不可变历史快照。

正式任务在开始逐标的下载前显示目标数量和可用空间。日线、1 分钟状态、合规截止日期和逐日校验结果分别持久化；瞬时网络错误最多重试一次，协议错误直接报告并回退，可取消、恢复、仅重试失败项。纯追加只写新增日期所属分片，历史修订只重验相关交易日。

等价 CLI 及小范围同步：

```powershell
uv run --frozen stockregression data sync --frequency 1day --scope market --mode history --start 2015-01-01 --resume
uv run --frozen stockregression data sync --frequency 1day --scope market --mode incremental --resume
uv run --frozen stockregression data sync --frequency 1min --mode repair --symbol 600000.SH --start 2026-09-28 --end 2026-10-16
uv run --frozen stockregression data sync --frequency 15min --scope watchlist --mode incremental --resume
uv run --frozen stockregression data probe --source tdx --capability recent_minute --market all
uv run --frozen stockregression data probe --source eastmoney --capability etf_daily --market etf
```

不指定代码或范围时使用自选列表。CLI 会输出进度和报告 JSON 路径；部分目标失败退出码为 2，全部失败为 1，逐标的原因仍保留。API `/api/v1/data/sync-status` 提供同步任务记录、当次日线/分钟截止日期和分页，完整报告保存在 `results/`；这些历史任务记录不代表后来导入或合并后的当前完整性，当前状态见 `/api/v1/data/coverage/{symbol}`。

### 数据来源和实际覆盖

股票与 ETF 使用同一套来源治理。BaoStock 提供股票和 ETF 的未复权日线、交易日历及股票公司行动；ETF 日线默认也使用 BaoStock。AKShare 的新浪分钟接口提供近期 1 分钟行情，ETF 分红和拆分资料来自 AKShare。5/15/30/60 分钟、周线和月线由本地基础数据生成。东方财富 ETF 日线与通达信近期分钟保留为可选来源，只有手动探测通过后才能切换；运行失败会记录具体接口、错误类别和 24 小时冷却，并在当前请求中回退一次默认来源。

**1 分钟历史行情只从当前数据包读取，不再从 Hugging Face 或其他在线历史库下载。** 页面中的 1 分钟历史初始化入口已移除；更早的分钟记录需要通过数据包登记、文件夹导入或单文件导入补齐。线上增量与缺口修补只覆盖新浪接口实际返回的近期窗口，超出窗口的缺口继续保留为待导入，不会被误报为已补齐。

“全市场任务完成”表示已处理目标目录，不代表每只证券都有完整历史分钟线。来源可能限流或暂时不可用；实际日期、标签、量纲、日线降级、分红核验和缺口以同步报告与质量日历为准。打开数据管理页只读取来源健康缓存，不会主动联网；需要复测时提交“检测”任务，结果在任务完成后共享给后续所有任务。

上述来源限制是接口的能力记录。标的当前是否齐备，以本地合并后的数据为准：行情、回测、参数研究统一展示当前校验结果和手动导入／接口同步的实际区间；已补齐数据不会继续继承旧下载失败提示。深市收盘集合竞价的零量估值占位与真实分钟缺口分别统计，已有本地数据完整时不为这些占位重复下载。详见[分钟质量规则](docs/data-format.md#分钟质量核验与回测降级)。

## 行情页面

“行情”提供自选、代码/名称搜索、股票/ETF 筛选、K 线和成交量。支持日线及 1/5/15/30/60 分钟、缩放、十字光标、加载更早行情；默认 MA5、MA10、MA20、MA60，修改逗号分隔的周期后离开输入框即可生效，留空关闭。均线包含展示区间之前的足够数据，翻页不会重新从零计算。

提供更新当前证券、更新自选和数据包内已有证券的快捷入口。任务完成后刷新本地行情和覆盖状态；完整导入、初始化、质量报告、存储与计划位于“数据管理”。行情浏览与严格回测校验分离：未核验价格可查看并带有来源说明；回测不会把未核验分钟当成可靠路径。

## 股数回测与定投

新配置保存为 `schema_version=2`。默认初始持股 1000、最低持股 0、最高持股 2000，每次买入、卖出和定投 100。ETF 使用“份”；仓位与交易计量均为整数数量。所有数量按 100 递增，正交易量至少 100，科创板买入和定投至少 200；最低 ≤ 初始 ≤ 最高。

初始持股表示开始前已经拥有的股份，按开始前最近有效交易日收盘价估值，首日即可卖出，不虚构建仓成交或建仓费用。固定可用现金留空时，系统按最高持股与初始持股之差、参考价、买入分笔费用和滑点推算预留现金；也可直接指定现金预算。载入科学研究参数会保留研究锁定的现金，结果展示预留现金和起始总资产。成交继续受实际可用现金、持股上下限、费用、价格限制和 T+0/T+1 约束。

日期默认为上海时区一年前至今天，闰日按上一年当月有效日期处理。改变标的或开始日期会读取**开始日期之前**最近的本地有效交易日收盘价并显示所属日期；可手工修改网格参考价，初始持股估值仍采用历史收盘价。缺少行情或前置历史时，预览、正式回测和参数搜索返回具体缺口，不会自动下载，也不使用区间内未来价格代替估值。结束日期保留用户填写值，同时显示实际截止和滞后提示；补数后仍无有效区间则停止计算。

移动网格显示买入、卖出步长；等差/等比网格显示网格间距，隐藏参数不提交或参与搜索。等差每格金额 = 参考价 × 网格间距；等比按比例划格。佣金默认 `0.05%`（内部 `0.0005`），最低佣金默认 `0.1` 元，支持连续输入小数。这两个字段的有效修改会自动记入本机设置，重启、新建或重置时填充上次值；载入已保存配置采用该配置的费用，载入动作不覆盖个人记忆。

“策略回测”和“参数研究”共用本机记住的默认设置，但切换页面时各页保留当前草稿；显式点击“用当前配置研究”或载入研究候选才会更新另一页配置。刷新或重启时标的留空，点击输入框显示最近提交过回测或参数研究的 10 个去重标的，包含失败或取消的已提交任务；输入代码或名称后切换为证券搜索。网格规则、仓位与交易量、定投设置、参数研究设置与完整搜索范围的有效编辑会自动记入本机设置，跨标的共用。空输入和无效中间值不会覆盖上次有效值；载入已保存配置或研究候选不会改写个人记忆。“恢复上次参数”恢复四组记忆、清空标的并使用新的默认日期；“恢复默认范围”仅重置并记忆研究搜索范围。

定投支持独立初始仓位、每天／每周／每月频率和每期股数。初始仓位默认 0 股／份，按开始前最近有效收盘价认定期初投入，不虚构建仓费用，也不占用首期定投。之后每期在首个可成交交易日开盘独立投入指定数量所需金额及手续费，不从网格现金扣款；整期无法成交时记录跳过，不跨期补投。

全仓持有使用独立的期初 1000 股／份、零现金账户，按开始前收盘价认定投入，不产生首日建仓交易。它不受网格初始资金、持股上下限、网格参考价和步长影响；股息留在账户内，不追加外部投入。

```text
资产投入比 =（当前现金 + 持仓市值 + 应收权益）÷ 累计投入
累计盈利 = 当前资产总值 − 累计投入
收益率曲线 = 资产投入比 − 1
```

工作台和结果分析将网格交易、全仓持有、定投放在同一张收益率曲线图中，纵轴为百分比，`1.10` 对应 `10%`，盈亏平衡线为 `0%`。网格投入为期初持股估值加预留现金，账户内卖出回款和重复买入不增加投入；定投投入为期初持股估值加每期成功买入的成交金额及费用。新增投入不构成盈利，分红不增加投入；累计投入为零时曲线和收益率为空。回撤图补充定投按每日收盘资产投入比相对历史峰值的回落，峰值初始基准为 1，尚未投入时留空；定投不套用固定本金的年化、夏普或月年收益算法。持股数量图仅展示网格策略。

有效参数停止修改 600ms 后自动预览。预览复用正式成交内核、锁定数据快照并缓存行情预处理，只返回每日曲线和摘要；同页仅保留最新待算参数，旧响应不会覆盖新曲线。计算期间标明旧曲线状态，预览不生成永久任务或结果，只在本地已有数据就绪时开始。“运行回测”保存完整成交、拒单及快照，详细曲线、交易明细和导出在“结果分析”。

计算前先检查请求区间、前置估值收盘、交易日历、目标周期和公司行动资料。API 返回 `DATA_NOT_READY` 及结构化缺口，页面提供“去准备数据”入口；提交数据任务后才会联网。严格回测要求目标周期质量覆盖本次请求；分钟数据不完整时仍可浏览，但不会把不完整分钟伪装成可执行策略。缺少必要日线、日历或公司行动资料时同样停止计算，已验证的可用行情保留供以后复用。新数据通过质量检查后发布不可变快照，计算锁定该快照。

旧现金/比例配置与旧结果保留。载入旧配置时，按开始前历史参考价换算成股数草稿并显示说明，缺少定投初始仓位时补 0；另存后为新版本，不自动覆盖原配置。新结果带有独立账户计算口径标记，历史结果按原始记录展示并注明旧口径；重新运行才应用新规则。

## 参数研究

新研究默认使用**科学参数研究 v2**：所选日期是样本外评估区间，系统检查本地是否具备开始日前 504 个交易日的历史，缺少时返回准备范围。固定方案在评估开始前选择一次，自适应方案每 63 个交易日只使用当时已有历史重选；两者共享固定的初始持股与现金预算，换参延续账户和公司行动。

候选生成、四段时间验证、参数邻域和双成本压力采用预先固定的规则。总是提供可计算候选中的相对最佳，同时分别显示约束、样本充分性和统计证据。末 126 日检验使用实际连续账户收益，记录重复验证日期；最新参数的历史重跑明确标为样本内回看。默认每个决策点 1000 次基础试验，邻域、压力及统计计算量另行记录；取消保留已经完成的研究记录。完整方法见[科学参数研究协议](docs/scientific-selection.md)，真实行情、时序隔离与加速一致性见[159611 验收报告](docs/159611-scientific-acceptance.md)。

旧版历史搜索和单次留出研究保留查看与兼容入口，以下为旧协议说明：

“策略回测”页运行预览和正式回测，参数通过“用当前配置研究”复制到独立的“参数研究”页。研究页按“研究对象与评估区间 → 研究设置与范围 → 启动研究 → 解读结果并载入回测”组织；常用设置和启动入口常驻，搜索范围、约束、复现设置及详细证据按需展开。载入研究候选会更新回测草稿并保留选参截止日。直接搜索整数股数，只展示、验证和搜索当前网格模式的有效参数。可选历史搜索、稳健研究或两种模式，默认每种 200 次，最大每种 5000 次；`both` 最多运行 2×N 次搜索，另有验证与测试计算。

稳健研究保留默认至少 504 个交易日、分钟覆盖率和最少成交要求。默认一年区间通常不足，界面会说明并提供扩展到本地可用历史入口。训练、验证、测试各自按分段之前的真实收盘重新初始化股份与预留现金；训练选候选、验证选参数、最终测试仅评估一次。推荐参数可载入工作台检查和保存。

## 自动更新计划

默认周一至周五 **18:30** 先更新数据包中已有证券的**日线**，再更新已有 **1 分钟**数据，周六 **10:00** 修补日线缺口，使用真实交易日历和实际已收盘日期取数。新证券需要明确提交初始化任务；1 分钟历史只从本地数据包或导入文件建立。时间可在“数据管理”或“行情”的本机设置中编辑。网页关闭后 Windows 任务仍可运行。

```powershell
uv run --frozen stockregression schedule install
uv run --frozen stockregression schedule status
uv run --frozen stockregression schedule remove
```

安装会注册 `StockRegression-Daily` 与 `StockRegression-Weekly`，以当前 Windows 登录用户交互身份运行、隐藏启动窗口、错过时尽可能补执行、同一任务不重复启动。无人登录的服务账户场景未配置。`status` 返回应用保存的设置；系统实时执行状态请在 Windows 任务计划程序查看。保存已启用计划的新时间会重新注册任务。

## 导入、演示和本地目录

正式基础周期只有 **1min、1day**；其余周期从二者按需聚合并持久化。数据包中的历史分钟文件直接按标的读取，日线从集中文件按代码过滤，新增和修订写增量分片；DuckDB 负责字段映射、时间过滤和缓存，SQLite 保存可重建索引、逐日校验与合规截止。“数据管理”页按证券展示各周期、文件、覆盖、合规和归档状态，并提供数据包登记、单文件与文件夹批量导入、线上基础周期更新、新证券初始化、准备任务、按需聚合和任务报告。完整说明见[周期行情数据管理](docs/market-data.md)。

本地文件导入只读取指定的日线或 1 分钟文件，不自动联网补齐其他周期。缺少日历、日线状态或时间标签依据时，记录先入库并标记待核验。回测、预览和参数研究只读取本地数据；缺少粗周期时自动从基础数据生成，基础数据不足时返回明确的准备范围和入口。

```powershell
uv run --frozen stockregression data import-file --frequency 1day --path .\imports\1day\600000.parquet --calendar-path .\calendar.csv
uv run --frozen stockregression data import-folder --frequency 1min --dry-run
uv run --frozen stockregression data sync --frequency 1day --mode incremental --scope watchlist
```

## 模型与覆盖限制

- 真实收盘产生网格信号，后续真实开盘执行；合成条不触发成交，开盘封板保守拒单。日线降级不能恢复盘中路径。
- ETF 按资料中的类型使用 0.001 元精度、100 份单位、对应涨跌幅和 T+0/T+1；ETF 不套用股票印花税和股票过户费。分类推断应结合证券资料核对，导入可覆盖类型。具体口径和来源见[回测规则](docs/rules.md)。
- 分红按税前计入；拆分、配股、合并等缺少必要日期或未建模事件会阻止相关区间回测。ETF 分红/拆分资料未核验的区间可浏览，但须补齐后才能严格回测。
- 股票早期过户费不完整年份采用明确估算；不会将当前费率静默套到所有历史。训练和测试结果仅反映所用数据与模型。

验收范围、联网来源检查与限制见[验收记录](docs/validation.md)。运行检查：`uv run --frozen pytest -q`，以及 `frontend` 目录下的 `npm test`（Node.js 24）和 `npm run build`。

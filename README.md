# A 股网格回测与参数研究台

这是一个仅在本机运行的中文研究工作台，用于整理沪深 A 股行情、配置网格回测、比较定投和买入持有基准，并对参数做历史搜索及按时间分段的样本外验证。行情、配置、任务日志和结果保存在本机；网页服务默认只监听 `127.0.0.1`。

演示行情由程序生成，并会带有 `is_demo` 标记和醒目的“演示数据”提示。演示行情不是真实历史数据，不能用来证明策略表现。真实行情必须通过同步或导入获得；本项目不会用演示行情填充真实行情缺失区间。

## 环境与启动

Windows 环境请准备 Python 3.12、`uv`、Node.js 和 npm。首次在项目根目录执行：

```powershell
uv sync --python 3.12
cd frontend
npm ci
npm run build
cd ..
```

然后启动网页：

```powershell
uv run stockregression serve --open-browser
```

也可双击项目根目录的 `start.cmd`，或在 PowerShell 中运行 `start.ps1`。启动脚本会先执行 `uv sync --python 3.12`；如果尚无 `frontend/dist/index.html`，会自动执行 `npm ci` 与 `npm run build`，随后启动服务并打开浏览器。服务地址默认为 <http://127.0.0.1:8000>。API 文档可在服务启动后访问 <http://127.0.0.1:8000/docs>。

修改了前端源码后，在 `frontend/` 目录重新运行 `npm run build`，再刷新网页。启动脚本只在构建产物缺失时自动构建，不会检测源码是否比现有产物更新。

## 常用流程

### 准备证券清单和数据

在数据中心点击“更新股票列表”，任务完成后可按代码或名称搜索沪深股票并加入自选。也可以直接在命令行同步：

```powershell
uv run stockregression sync --mode history --symbol 600000.SH
uv run stockregression sync --mode daily --symbol 600000.SH
uv run stockregression sync --mode repair --symbol 600000.SH
```

`--symbol` 可重复指定多只股票；不指定时使用自选列表。`history` 请求历史分钟数据并更新日线、交易日历和公司行动；`daily` 做日常增量更新；`repair` 请求近期窗口补齐。各来源的可服务窗口、联网状态和个股覆盖并不保证完整，运行后请在数据中心检查覆盖日历、分钟覆盖率、来源校准状态和任务警告。不同来源暂不可用时，后端会保留警告，不会将未核验分钟记录当作可靠的分钟回测数据。

数据同步会使用固定版本的 Hugging Face 历史分钟数据，并请求 BaoStock 的不复权日线、交易日历和公司行动；近期分钟窗口先尝试通达信，遇到错误时再尝试新浪分钟备源。历史分钟标签若无法通过日线核验，还会尝试用独立的 BaoStock 5 分钟参考数据校准一个有限近期窗口。实际可获得的数据取决于来源当前状态及股票历史，独立参考的样本范围有限。不要把“任务完成”理解为所有日期都有完整分钟覆盖。

### 生成演示数据

首次体验可在数据中心使用“生成演示数据”，或运行：

```powershell
uv run stockregression demo --symbol 000001.SZ --days 780
```

后端生成确定性的模拟走势，交易日数限制为 20–1600，并显式标记为演示数据，示例中含有短缺口和整日降级。此流程是用于体验界面和验证计算管线，不是任何股票的真实行情。演示数据不能覆盖已有真实数据；真实历史同步会建立新的真实数据快照。

### 导入自己的 CSV / Parquet

网页数据中心可以填写本机可访问的行情文件路径，或使用 CLI：

```powershell
uv run stockregression import-data 600000.SH .\daily.csv `
  --minute-path .\minute.csv `
  --actions-path .\actions.csv `
  --calendar-path .\calendar.csv `
  --label-convention end
```

其中 `600000.SH` 和 `daily.csv` 是必需的位置参数，不要写成 `--symbol` 或 `--daily-path`；CLI 每次都要求提供日线文件参数，网页在已有本地日线时可省略。分钟、公司行动、交易日历路径是可选选项；首次导入至少要有日线文件。示例中的 `--label-convention end` 假定分钟时间戳是 bar-end；请先核对数据供应方定义，若表示分钟开始时间则改为 `start`。不确定时可省略该选项，默认自动校准；无法确认标签的数据日会按日线处理。详细字段要求和质量核验规则见[数据文件格式说明](docs/data-format.md)。如果未提供交易日历文件，导入会尝试获取真实交易日历；若来源不可用，必须提供真实交易日历文件，系统不会将普通工作日当作交易日。

### 运行回测并查看结果

在“回测工作台”配置代码、日期、频率、现金与仓位、网格模式和网格步长、基准价/价格边界、买卖数量、费用及定投频率。界面中的百分比会转换为 API 使用的 `0..1` 小数。保存配置后可载入、复制、删除，也可以选中多份配置独立批量回测。回测要求所选区间有可用本地数据；结束日期不能超过本地日线数据完整截止日。

在“结果分析”可查看网格、定期定额和买入持有三类策略的净值、回撤、持仓、交易点、成交、拒单以及由净值计算的年/月收益。页面曲线按每日收盘汇总，净值 CSV 与成交 CSV 保留回测结果的完整时间粒度；每个结果也可导出完整 JSON。若数据质量报告包含整日降级或警告，应结合覆盖日历解读结果。

### 研究参数并载入推荐

在“参数研究”设置基准配置、历史/稳健/两种模式、参数范围、随机种子、回撤与最少成交约束。稳健模式按时间顺序切分为训练、验证、测试段：训练段用于搜索和排序，领先候选进入验证段筛选，选出的参数只在测试段评估一次。它减少直接用全样本挑选参数造成的前视偏差，但不能保证未来表现。

`n_trials` 是**每种搜索试验次数**，默认 200、最大 5000。选择 `both` 时历史搜索和稳健训练各运行 N 次，搜索试验总数最多 `2 × N`；此外还会有候选验证、测试和结果回测计算。完成后页面分别展示历史收益最优与样本外推荐，可将任一参数载入回测表单，再检查配置并单独运行。

## 自动更新计划

数据中心“本机存储与计划”可编辑每日时间、每周星期和每周时间，保存后安装/更新系统计划。也可在 Windows 命令行操作：

```powershell
uv run stockregression schedule install
uv run stockregression schedule status
uv run stockregression schedule remove
```

`install` 会在 Windows 任务计划程序中注册 `StockRegression-Daily`（周一至周五运行日常更新）和 `StockRegression-Weekly`（按设定星期运行窗口修补）。任务以当前 Windows 登录用户的交互身份运行；它们不会在无人登录的服务账户下运行。计划设置为错过运行后尽可能补执行，并避免多个实例并发。`status` 显示应用保存的计划设置，不等同于从 Windows 任务计划程序读取的实时执行状态。网页方式更新已启用计划的时间时会重新注册任务。

## 数据目录和本地文件

默认数据目录为项目根目录下的 `data/`。网页“本机存储与计划”卡片会显示当前活动目录，也可填写并保存下次启动的数据目录；编辑草稿不会被后台刷新覆盖。也可通过 CLI 修改：

```powershell
uv run stockregression set-data-dir D:\market\stockregression-data
```

该命令不会搬迁或删除旧目录的数据；切换后旧数据仍保留在原位置。新目录在服务或 CLI 下次启动时生效。环境变量 `STOCKREGRESSION_DATA_DIR` 优先覆盖设置文件中的目录；`STOCKREGRESSION_HOME` 可指定项目/本地设置根目录。

默认数据目录的主要内容如下：

| 路径 | 内容 |
| --- | --- |
| `catalog.sqlite` | 证券、自选股、版本索引、任务、结果索引和保存的回测配置 |
| `parquet/<代码>/<类型>/<年份>/` | 分钟、日线、公司行动和交易日历的不可变 Parquet 分区 |
| `manifests/` | 数据快照清单和版本 |
| `results/` | 完整回测或优化结果 JSON |
| `logs/` | 任务异常的 Python 堆栈日志，以任务 ID 命名 |
| `raw/` | 后端保留的部分来源原始数据 |
| `source-probe/` | 本地来源探测记录（如存在） |

请定期备份整个数据目录；只复制 `catalog.sqlite` 而不复制其引用的 Parquet、manifest 和结果文件，并不能构成完整备份。改用新数据目录不会自动拷贝这些文件。

## 限制与解释边界

- 本版仅支持沪深 A 股代码；仅验证覆盖范围内的未复权行情。数据源可用性和服务窗口会变化，实际覆盖以本机质量报告为准。
- 分钟标签或成交量单位未经核验的日期会降级到日线回测。日线降级不恢复盘中价格路径；少量通过质量条件的分钟缺口会用前值补价并标记为合成条，回测不会用合成条触发交易。
- 导入数据必须有真实交易日历。为避免把停牌、上市前或节假日漏日当作正常交易，导入会从真实日历来源取交易日，或要求显式交易日历文件。
- 分红现金金额采用税前口径；个人投资者税负不在模型中。配股、合并、拆股等首版未建模的特殊公司行动会阻止相关回测。日线前收盘价出现无法由公司行动解释的除权变化也会报错，而不是静默继续。
- 2012 年 6 月以前的过户费历史口径不完整，相关费用按可获得资料估算并在结果说明中提示；2012 年 6 月至 2015 年按可核实的中国结算收费部分建模，佣金按券商合约费用计算，不含单列过户费。早期费率可在回测费用的“早期过户费设置”中根据券商资料调整。上市日期会影响部分板块上市初期的涨跌幅规则；导入日线时尽量提供 `listing_date` 列，避免因缺少上市日期而无法识别对应规则。
- 涨跌停成交校验依赖数据中可用的前收盘与涨跌停字段；若缺失，结果会带警告。所选区间跨越退市结算日期不受支持，请缩短区间。
- Windows 计划任务由当前登录用户运行。修改数据目录会在下次启动后生效；改目录不会搬移已有数据。
- 结果是历史数据和当前回测模型下的计算输出，不是投资建议，也不构成未来收益保证。

## 问题排查

| 现象 | 检查方法 |
| --- | --- |
| 股票检索没有结果 | 在数据中心点“更新股票列表”，等任务完成后重新搜索。检索来自已下载的本地证券清单。 |
| 回测提示无本地数据 | 先对该股票执行 `sync --mode history --symbol ...`，或在数据中心运行历史同步/导入。演示数据只适合流程体验。 |
| 某些天使用日线，分钟覆盖率偏低 | 查看 `profiles` 的校准状态、分钟标签、成交量倍率和原因；标签/单位不确定时，后端会选择日线而不是伪造分钟路径。可尝试用另一来源补齐或导入可核验的 1 分钟文件。 |
| 日线导入被拒绝 | 检查列名及 `preclose`、`tradestatus`、`is_st`（或 `isST`）历史字段。首次导入还必须有日线和可用的真实交易日历。 |
| 导入时间错一根或量级不对 | 确认供应方的 bar-start/bar-end 标签，选择正确 `label_convention`；提供单位明确的原始量字段，并检查档案中的成交量倍率及核验天数。 |
| 提示交易日缺少日线 | 日线需覆盖真实交易日历中的全部日期，并包括确认停牌日状态。不要用工作日生成器补日历。 |
| 任务失败或被中断 | 查看数据中心任务日志的错误详情。若显示任务堆栈路径，可在 `logs/<任务ID>.log` 查看完整记录；应用退出会停止正在运行的子进程，可重新提交任务。 |
| 计划时间修改后未更新 | 确认网页提示重新注册成功；用 `uv run stockregression schedule install` 更新系统任务，并使用 Windows 任务计划程序核对当前登录用户下的 `StockRegression-Daily` / `StockRegression-Weekly`。 |
| 改了数据目录但网页仍显示旧目录 | 这是预期行为：正在运行的服务保留启动时的数据根目录。关闭后重新启动，确认没有 `STOCKREGRESSION_DATA_DIR` 覆盖设置。 |
| 页面/API 无法连接 | 运行 `uv run stockregression serve --open-browser`，检查 <http://127.0.0.1:8000/api/v1/health>。不要将本机服务地址替换为局域网或公网地址。 |

详细的 CSV/Parquet 字段规范和格式示例见[数据文件格式说明](docs/data-format.md)。

本机真实行情接入、三策略结果、200 次参数搜索、自动更新任务及验收场景见[验收记录](docs/validation.md)；计算内核性能记录见[性能测量 JSON](docs/performance.json)。

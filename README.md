# A 股及 ETF 行情与网格研究台

基于 FastAPI、React、SQLite 和 Parquet 的本地中文研究工作台，支持沪深 A 股及场内 ETF 行情浏览、全市场同步、股数网格回测、固定股数定投和参数研究。界面按 1920×1080 桌面设计，“回测与研究”共用参数、三策略曲线和运行入口，进度显示在操作附近。服务默认只监听 `127.0.0.1`；行情、配置、任务和结果保存在本机。

演示数据带有醒目标识，用于体验界面和检查计算流程。真实行情必须通过同步或导入获得，系统不会用演示数据补齐真实历史缺口。

## 启动

Windows 需要 Python 3.12、`uv`、Node.js 和 npm。直接双击 `start.cmd` 或运行：

```powershell
.\start.ps1
```

启动脚本执行 `uv sync --frozen --python 3.12`，在构建缺失或前端源码、构建配置有更新时执行 `npm ci` 和 `npm run build`，然后启动服务并打开浏览器。默认地址为 <http://127.0.0.1:8000>，API 文档为 <http://127.0.0.1:8000/docs>。

手动安装、构建和启动：

```powershell
uv sync --frozen --python 3.12
Push-Location frontend
npm ci
npm run build
Pop-Location
uv run --frozen stockregression serve --open-browser
```

## 首次全市场同步与后续更新

全市场范围来自完整本地证券目录，合并固定历史库清单与当前上市股票、ETF 清单，包括来源保留的退市历史。全市场同步不会自动加入自选，也不受网页搜索结果条数限制。

交付脚本 `sync-market.ps1` 默认做可恢复的历史同步，下载并发为 2。请先查看预计规模及磁盘空间，再自行启动正式全量任务：

```powershell
# 仅预检目录数量、可得的历史分钟文件大小和磁盘空间，不下载行情
.\sync-market.ps1 -DryRun

# 首次历史同步；结束后安装盘后增量与周末修补计划
.\sync-market.ps1 -InstallSchedule

# 中断后继续：跳过同一历史源版本已经完成的标的
.\sync-market.ps1

# 只重新尝试同一任务范围内的失败标的
.\sync-market.ps1 -RetryFailed

# 手动执行全市场日常增量或近期窗口修补
.\sync-market.ps1 -Mode daily
.\sync-market.ps1 -Mode repair

# 忽略已完成检查点，重新核对全部目标；相同记录仍按时间去重
.\sync-market.ps1 -Fresh
```

预检会访问小规模目录、文件元数据，来源缓存可能更新；不会创建行情同步任务。准确下载量不可得时会明确提示。预计大小仅涵盖固定历史分钟文件，不含日线、原始缓存、解压与 Parquet 分区和旧快照；全市场应预留数十 GB 以上并根据预检留出额外空间。

正式任务在开始逐标的下载前再次显示目标数量、源文件预计大小和可用空间。日线、分钟状态及截止日期分别持久化，失败自动限次重试；可取消、恢复、仅重试失败项。重复运行合并重叠记录，只重写受影响的年度分区，复用未变化文件；旧快照继续用于历史结果复现。历史任务检查点按来源版本区分，日常任务按本地已收盘日期区分。

等价 CLI 及小范围同步：

```powershell
uv run --frozen stockregression sync --scope market --mode history --resume
uv run --frozen stockregression sync --scope market --mode daily --resume
uv run --frozen stockregression sync --mode history --symbol 600000.SH --symbol 510300.SH
uv run --frozen stockregression sync --scope watchlist --mode daily
```

不指定代码或范围时使用自选列表。CLI 会输出进度和报告 JSON 路径；部分目标失败退出码为 2，全部失败为 1，逐标的原因仍保留。API `/api/v1/data/sync-status` 提供状态、日线/分钟截止日期和分页，完整报告保存在 `results/`。

### 数据来源和实际覆盖

股票与 ETF 使用独立适配器：股票使用固定版本历史分钟库、BaoStock 不复权日线、真实交易日历及公司行动，并尝试通达信 / 新浪近期分钟；BaoStock 会话访问串行化。ETF 使用独立固定历史库及东财日线、基金分红/拆分资料，近期分钟同样尝试通达信 / 新浪，日历仍来自真实交易日历。每次市场任务尝试发现新上市证券；当前清单来源失败时会在报告中提示覆盖风险。

**“全市场任务完成”表示已处理目标目录，不代表全市场每只证券都有完整历史分钟线。** 当前 [ETF 历史分钟库](https://huggingface.co/datasets/neigezhu/china-etf-1min-ohlcv)覆盖 7 只标的；近期分钟备源为新浪 1 分钟接口，约覆盖 8 个交易日（东财 trends2 分钟接口对历史交易日返回开盘价 0.000，已不再作为 ETF 分钟备源）。来源随时可能限流或不可用，实际日期、标签校准、日线降级、分红核验和缺口以本机同步报告与质量日历为准。缺少的历史可通过本地导入补齐。

## 行情页面

“行情”提供自选、代码/名称搜索、股票/ETF 筛选、K 线和成交量。支持日线及 1/5/15/30/60 分钟、缩放、十字光标、加载更早行情；默认 MA5、MA10、MA20、MA60，修改逗号分隔的周期后离开输入框即可生效，留空关闭。均线包含展示区间之前的足够数据，翻页不会重新从零计算。

提供“一键更新全市场”“更新当前”“更新自选”。任务完成后刷新本地行情和覆盖状态；历史同步、导入、质量报告、存储与计划位于辅助区域。行情浏览与严格回测校验分离：未核验价格可查看并带有来源说明，图表保持所选真实周期；回测不会把未核验分钟当成可靠路径。

## 股数回测与定投

新配置保存为 `schema_version=2`。默认初始持股 1000、最低持股 0、最高持股 2000，每次买入、卖出和定投 100。ETF 使用“份”；仓位与交易计量均为整数数量。所有数量按 100 递增，正交易量至少 100，科创板买入和定投至少 200；最低 ≤ 初始 ≤ 最高。

初始持股表示开始前已经拥有的股份，按开始前最近有效交易日收盘价估值，首日即可卖出，不虚构建仓成交或建仓费用。系统按最高持股与初始持股之差、参考价、买入分笔费用和滑点推算预留现金，界面只读展示预留现金和起始总资产。成交继续受实际可用现金、持股上下限、费用、价格限制和 T+0/T+1 约束。

日期默认为上海时区一年前至今天，闰日按上一年当月有效日期处理。改变标的或开始日期会请求**开始日期之前**最近交易日收盘价并显示所属日期；可手工修改网格参考价，初始持股估值仍采用历史收盘价。缺少行情或前置历史时，预览、正式回测和参数搜索自动准备当前标的数据，不使用区间内未来价格代替估值。结束日期保留用户填写值，同时显示实际截止和滞后提示；补数后仍无有效区间则停止计算。

移动网格显示买入、卖出步长；等差/等比网格显示网格间距，隐藏参数不提交或参与搜索。等差每格金额 = 参考价 × 网格间距；等比按比例划格。佣金默认 `0.05%`（内部 `0.0005`），最低佣金默认 `0.1` 元，支持连续输入小数。这两个字段的有效修改会自动记入本机设置，重启、新建或重置时填充上次值；载入已保存配置采用该配置的费用，载入动作不覆盖个人记忆。

“回测与研究”每次进入时标的留空，点击输入框显示最近提交过回测或参数研究的 10 个去重标的，包含失败或取消的已提交任务；输入代码或名称后切换为证券搜索。网格规则、仓位与交易量、定投设置、参数研究设置与完整搜索范围的有效编辑会自动记入本机设置，跨标的共用，返回页面、刷新或重启后默认填充。空输入和无效中间值不会覆盖上次有效值；载入已保存配置或研究候选不会改写个人记忆。“恢复上次参数”恢复四组记忆、清空标的并使用新的默认日期；“恢复默认范围”仅重置并记忆研究搜索范围。

定投支持独立初始仓位、每天／每周／每月频率和每期股数。初始仓位默认 0 股／份，按开始前最近有效收盘价认定期初投入，不虚构建仓费用，也不占用首期定投。之后每期在首个可成交交易日开盘独立投入指定数量所需金额及手续费，不从网格现金扣款；整期无法成交时记录跳过，不跨期补投。

全仓持有使用独立的期初 1000 股／份、零现金账户，按开始前收盘价认定投入，不产生首日建仓交易。它不受网格初始资金、持股上下限、网格参考价和步长影响；股息留在账户内，不追加外部投入。

```text
资产投入比 =（当前现金 + 持仓市值 + 应收权益）÷ 累计投入
累计盈利 = 当前资产总值 − 累计投入
收益率曲线 = 资产投入比 − 1
```

工作台和结果分析将网格交易、全仓持有、定投放在同一张收益率曲线图中，纵轴为百分比，`1.10` 对应 `10%`，盈亏平衡线为 `0%`。网格投入为期初持股估值加预留现金，账户内卖出回款和重复买入不增加投入；定投投入为期初持股估值加每期成功买入的成交金额及费用。新增投入不构成盈利，分红不增加投入；累计投入为零时曲线和收益率为空。回撤图补充定投按每日收盘资产投入比相对历史峰值的回落，峰值初始基准为 1，尚未投入时留空；定投不套用固定本金的年化、夏普或月年收益算法。持股数量图仅展示网格策略。

有效参数停止修改 600ms 后自动预览。预览复用正式成交内核、锁定数据快照并缓存行情预处理，只返回每日曲线和摘要；同页仅保留最新待算参数，旧响应不会覆盖新曲线。计算期间标明旧曲线状态，预览不生成永久任务或结果；自动获取的行情和质量记录会保存本地。“运行回测”保存完整成交、拒单及快照，详细曲线、交易明细和导出在“结果分析”。

自动准备先检查当前请求区间、估值收盘、交易日历和分钟覆盖，再按需要使用历史或增量同步。同一标的的并发请求复用准备结果；已知来源缺口不会因修改网格参数反复下载，网络失败短暂退避后可重试。新数据通过质量检查后发布不可变快照，计算锁定该快照。缺分钟但日线合格时允许整日降级并提示覆盖率；缺少必要日线、日历或公司行动资料时停止计算，已验证的可用行情保留供以后复用。

旧现金/比例配置与旧结果保留。载入旧配置时，按开始前历史参考价换算成股数草稿并显示说明，缺少定投初始仓位时补 0；另存后为新版本，不自动覆盖原配置。新结果带有独立账户计算口径标记，历史结果按原始记录展示并注明旧口径；重新运行才应用新规则。

## 参数研究

“回测与研究”在同一页提供“运行回测”和“搜索参数”，共用表单、日期、参考价及预览。搜索设置、范围和高级约束可展开，结果和候选展示在下方，载入最优参数直接更新当前草稿。进度位于操作区域，历史任务可展开查看。直接搜索整数股数，只展示、验证和搜索当前网格模式的有效参数。可选历史搜索、稳健研究或两种模式，默认每种 200 次，最大每种 5000 次；`both` 最多运行 2×N 次搜索，另有验证与测试计算。

稳健研究保留默认至少 504 个交易日、分钟覆盖率和最少成交要求。默认一年区间通常不足，界面会说明并提供扩展到本地可用历史入口。训练、验证、测试各自按分段之前的真实收盘重新初始化股份与预留现金；训练选候选、验证选参数、最终测试仅评估一次。推荐参数可载入工作台检查和保存。

## 自动更新计划

默认周一至周五 **18:30** 全市场增量，周六 **10:00** 全市场修补，使用真实交易日历和实际已收盘日期取数。时间可在“行情 → 数据覆盖、历史同步、导入与本机更新计划 → 本机存储与计划”编辑。网页关闭后 Windows 任务仍可运行。

```powershell
uv run --frozen stockregression schedule install
uv run --frozen stockregression schedule status
uv run --frozen stockregression schedule remove
```

安装会注册 `StockRegression-Daily` 与 `StockRegression-Weekly`，以当前 Windows 登录用户交互身份运行、隐藏启动窗口、错过时尽可能补执行、同一任务不重复启动。无人登录的服务账户场景未配置。`status` 返回应用保存的设置；系统实时执行状态请在 Windows 任务计划程序查看。保存已启用计划的新时间会重新注册任务。

## 导入、演示和本地目录

“行情”的辅助区域支持本机 CSV / Parquet 导入，或运行：

```powershell
uv run --frozen stockregression import-data 600000.SH .\daily.csv --minute-path .\minute.csv --actions-path .\actions.csv --calendar-path .\calendar.csv --label-convention end
uv run --frozen stockregression import-data 518880.SH .\etf-daily.csv --etf-category commodity --calendar-path .\calendar.csv
uv run --frozen stockregression demo --symbol 000001.SZ --days 780
```

CLI 的代码、日线文件为两个必需位置参数；分钟、公司行动、日历可选。ETF 类型可明确指定 `stock/bond/crossborder/commodity/money`；股票无需填写。准确字段、时区与质量规则见[数据文件格式](docs/data-format.md)。没有日历文件时会请求真实日历，来源失败时必须补文件，不能用普通工作日列表替代。

默认目录为 `data/`；可通过界面或 `uv run --frozen stockregression set-data-dir D:\market\stockregression-data` 修改，下次启动生效，旧文件不会迁移或删除。环境变量 `STOCKREGRESSION_DATA_DIR` 优先覆盖设置；`STOCKREGRESSION_HOME` 指定本地设置根目录。

| 路径 | 内容 |
| --- | --- |
| `catalog.sqlite` | 证券、自选、快照索引、逐项同步检查点、配置与任务 |
| `parquet/<代码>/<类型>/<年份>/` | 不可变行情、公司行动和日历分区 |
| `manifests/` | 数据快照清单 |
| `results/` | 完整回测、研究和同步报告 JSON |
| `logs/` | 失败任务的完整异常记录 |
| `raw/` | 部分来源原始缓存 |

请备份整个活动数据目录，SQLite 单文件不包含引用的 Parquet、快照与结果。重复执行数据库迁移不会删除旧配置或结果。

## 模型与覆盖限制

- 真实收盘产生网格信号，后续真实开盘执行；合成条不触发成交，开盘封板保守拒单。日线降级不能恢复盘中路径。
- ETF 按资料中的类型使用 0.001 元精度、100 份单位、对应涨跌幅和 T+0/T+1；ETF 不套用股票印花税和股票过户费。分类推断应结合证券资料核对，导入可覆盖类型。具体口径和来源见[回测规则](docs/rules.md)。
- 分红按税前计入；拆分、配股、合并等缺少必要日期或未建模事件会阻止相关区间回测。ETF 分红/拆分资料未核验的区间可浏览，但须补齐后才能严格回测。
- 股票早期过户费不完整年份采用明确估算；不会将当前费率静默套到所有历史。训练和测试结果仅反映所用数据与模型。

验收范围、联网来源检查与限制见[验收记录](docs/validation.md)。运行检查：`uv run --frozen pytest -q`，以及 `frontend` 目录下的 `npm test`（Node.js 24）和 `npm run build`。

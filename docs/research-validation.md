# 完整研究验证 v1

完整验证把 v5 参数发现、八方案连续样本外回放、真实预算复测、ETF 筛选对照及压力测试保存为一条冻结研究。主方案始终为提交前指定窗口和先验设置的自适应分支，结果展示后不会自动替换主方案。本文的“完整”表示声明的必需单元完成，不表示全参数空间穷举或未来收益保证。

## 使用

参数研究页的“完整研究验证”填写标的池，以及每只标的的总预算、有限最高持股和可选计划补款。各标的是独立账户。先检查完整方案，核对实际历史、数据缺口、初始现金及工作量，然后提交。默认时限为24小时；取消、时限、预算或数据问题保留已经完成的单元。

自动方案只读冻结日历和质量证据，寻找截至截止日的连续可验证历史。设扣除前置估值日后的可用日数为N，训练下限、上限为m/M（通常250/500），训练T=min(M,max(m,floor(N/2)))，样本外O=min(504,N-T)。O不足63日时报告缺口，不跨缺口拼接。评价期按min(4,floor(O/63))个区块均分。显式模式使用用户的评价日期，不能自动裁剪。每个标的可以有不同历史；ETF对照使用共同决策日和相同的后续评价区间。

现有v5历史结果继续可读，但不会被补贴成已经完成新验证。训练候选参数图和J评分始终属于参数发现证据。

## 账户和撮合

训练J仍采用现有按成交补款口径。预算复测在选参完成后冻结参数/换参表，使用独立的`qualification_v1`政策，失败不会反向重新挑参数。

总预算包含初始持仓价值、初始现金和全部计划补款。初始持仓按开始前真实收盘估值，初始现金等于总预算减持仓价值减计划补款总额。只有已经到账的现金可买入，费用包含在现金检查内；补款未到账情景不会把该笔钱提前转成初始现金。资金不足撤销订单余量并继续账户。

信号在bar收盘产生，最早下一bar结束撮合；使用该bar收盘价格加不利滑点并按报价单位取整。默认参与率1%，部分成交余量等待最多3个bar，日终撤销；换参及反向信号取消旧单。每个bar的成交子单单独收取最低佣金。网格和预定入金持有基准接收相同的初始资产与计划入金，但各自拥有独立成交容量，基准入金不依赖网格成交。两账户都使用相同的税费、T+1、价格限制与公司行动规则。

成交量缺失和零量不同：缺失使相关资格不可评价，零量表示没有成交容量。bar成交容量是模拟代理，不包含真实订单簿队列。新模型的成交时点与原v5的次bar开盘模型分别标注。

## 方案、压力及证据

窗口（同价/固定）×先验（关闭/开启）×执行策略（固定/自适应）组成八方案。固定分支只在评价开始前选择一次，自适应分支按冻结周期滚动选择。账户、现金和权益跨块连续；分段本金以块首资产及块内外部资金流重建，分段收益不能直接求和。

没有合格参数是有效业务结果；暂停网格期间仍推进持仓估值和公司行动。数据异常、搜索/评分中止及预算停止属于未完成，不得与无合格参数混淆。

执行压力包含原条件、佣金及滑点翻倍、成交量减半、额外延迟一bar、最大补款缺失及叠加。没有补款时对应缺失项目标记不适用。各决策参数另外进行63个模拟交易日的固定参数价格压力（跌30%、涨30%、锚价±1%窄幅、受锚日制度限制的跳空）；不使用真实未来换参表，不把人造数据发布为市场行情。

ETF对照冻结当前本地候选池，在当时可见历史上形成无评分无过滤、仅评分、仅过滤、评分加过滤四种选择。评分取前三，未评分在相应池按固定种子抽取。未来结果缺失保留，不换人；共同样本不足时保持未完成。当前本地池无法证明包含全部历史退市/清盘成员，报告明确限制结论范围。

报告分别展示计算完成状态、候选状态、预算资格和证据范围。分段分布、差值和最差阶段属于描述性证据，不输出p值或未来盈利概率。

## 冻结、恢复与接口

- `POST /api/v1/research-validations/preview`接收`ResearchValidationRequest`，返回方案、版本和`plan_hash`。
- `POST /api/v1/research-validations`必须提交匹配的`plan_hash`，创建`research_validation`任务。
- `POST /api/v1/jobs/{id}/resume`恢复失败、取消或部分完成任务；可显式增加时限和评价预算，形成审计修订。
- `GET /api/v1/results/{id}`返回有界报告，`?full=true`及JSON导出流式展开完整账本；`export?kind=validation|equity|trades`导出CSV。
- `POST /api/v1/results/{id}/evidence-views`以`{"section":"overview"}`等明确记录查看。普通GET不记录查看，不启动计算。

研究族、父研究、计划/实际区间、方法指纹、失败与缓存事件保存在独立审计表。重叠区间只说明复用，不自动宣称污染；未记录查看也不能证明人未见过行情，因此`human_untouched_verified`保持false。

完整账本按不可变内容哈希压缩保存，检查点只引用账本；保存结果绑定不可变检查点快照，后续恢复不会改变旧报告的完整导出。恢复要求源码、依赖、数据和冻结数值设置一致，缓存复用不再次消耗评价次数。预算修订不删除原记录。

## 本地验收

以下金额仅为模拟验收输入，不产生真实交易：

```powershell
.\.venv\Scripts\python.exe scripts/acceptance_research_validation.py --budget 100000 --max-shares 3500
.\.venv\Scripts\python.exe scripts/acceptance_research_validation.py --budget 100000 --max-shares 3500 --run
```

脚本默认仅预检本地三只ETF，不下载、修补或修改市场行情。`--run`仅在冻结预检就绪时执行完整套件，否则保存真实数据缺口与未完成状态。默认报告位于`.local/research-validation-acceptance.json`。代码验收不以找到盈利参数为条件。

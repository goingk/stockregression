# 回测规则与历史口径

策略以真实bar收盘产生信号，下一根真实bar的开盘执行。补齐数据既不产生信号也不成交。开盘无法成交的订单取消。模型使用OHLCV，无法还原排队、临时停牌触发的逐笔路径或盘口价格笼子；开盘封板采取保守拒单。收益包含交易成本，现金分红按税前计入。

## 涨跌幅与上市初期

普通主板10%；历史ST主板在2026-07-06之前5%、之后10%。科创板20%，创业板从2020-08-24起20%，之前按原主板制度。上市日期配合完整交易日历计算新股第几个交易日，不能把数据区间的第一个交易日误当上市首日。

科创板、2020-08-24后注册制创业板、2023-04-10后注册制主板新股前5个交易日不设价格涨跌幅限制。2013-12-13起旧核准制IPO首日采用相对发行价144%/64%的全日有效价格边界，普通涨跌停从后续交易日生效。更早首日不套用常规10%限制。未模拟集合竞价阶段发行价80%–120%的申报范围及盘中临停排队；这类模型限制记录于规则说明。

## 交易费用

佣金是可编辑的券商合约费用，默认万3、最低5元；不含单列的过户费。印花税仅在卖出计入：本项目2010年起历史为千分之一，2023-08-28起减半为万分之五。各费用组件以成交金额精确到分、十进制半入后合计。

| 生效区间 | 沪市过户费 | 深市过户费 |
|---|---|---|
| 2012-06-01～2012-08-31 | 中国结算收取的成交面额×0.000375 | 成交金额×0.0000255 |
| 2012-09-01～2015-07-31 | 中国结算收取的成交面额×0.0003 | 成交金额×0.0000255 |
| 2015-08-01～2022-04-28 | 成交金额×0.00002 | 成交金额×0.00002 |
| 2022-04-29以后 | 成交金额×0.00001 | 成交金额×0.00001 |

过户费双向收取；旧沪市的“成交面额”以股数×股票面值计算，默认每股面值1元，可在早期费用设置中覆盖。2012～2015旧费率是官方中国结算收费口径，不能等同于所有券商向客户收取的历史合计费用。

2010～2012-05的中国结算完整费率沿革、旧最低费的全部调整日期未能由官方公开资料完整复原。该期明确使用估算并在结果中提示：沪市默认按2009上交所收费表的面额×0.001、最低1元，深市默认成交额×0.0000255，均可覆盖。不会将2015年后统一的成交金额比例套用到所有早期年份。

来源：[证监会2012年调费公告](https://www.csrc.gov.cn/csrc/c100028/c1002502/content.shtml)、[证监会2012年第8期新闻稿](https://www.csrc.gov.cn/csrc/c100024/c1492228/1492228/files/9265c0ec40074dcda1d45fc652106328.pdf)、[2015交易所/中国结算联合答问](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20150912_3988866.shtml)、[中国结算大事记](https://m.chinaclear.cn/zdjs/dsj/about_dsj.shtml)、[上交所旧收费表](https://www.sse.com.cn/aboutus/publication/factbook/documents/c/10170573/files/073e042b8b87407b919e3d8e75ee91a5.pdf)。

## 公司行动和期末

登记日按实际持股计权，除权日起应收现金和锁定送转股计入净资产；付款日现金可用，红股上市日股份可卖。网格价格和等差格距同时按行动机械调整。配股、合并等未实现事件或关键日期缺失阻止准确回测，不能用前复权价格直接作为交易价来绕过账户变化。

期末按持仓市值、现金和应收权益结算，不虚构强制卖出。未扣差异化红利税。训练/验证/测试各自从同一初始本金开始；没有在该分段登记日实际持有股份的账户不会得到此前分红。

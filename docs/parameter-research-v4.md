# 参数研究 v4：完整正收益连通域

新研究使用 `protocol_version=4`、`strategy_version=2`，推荐整片正收益连通域，同时标出参数最稳定点和超额收益最高点。历史策略 v1 继续按对称矩形邻域解释，旧结果不会自动转换为连通域；固定半宽平均收益模式保留为 v1。

## 参数空间与时间边界

研究只支持等比网格，维度为 `buy_step`、`sell_step`、`sell_shares`、`buy_shares`、`min_shares`、`max_shares`。初始持股固定；最高持股可选择固定不限。买卖间距以 0.01 个百分点（接口 `0.0001`）为单位，买卖数量以 100 股／份为单位，持仓上下限以 500 股／份为单位。搜索和去重始终使用整数刻度。

每个决策只读取该时点已收盘的数据，使用最近 504 个交易日：前 252 日训练并发现入口，后 252 日用于内部择参。

```text
f(x) = 网格峰值本金收益率(x) - 独立全仓持有收益率
```

验证账户在 `validation_start` 首日按初始配置重建，之后连续运行至 `validation_end`。四段分窗仅作诊断，不重置账户。保留 `validation_account_mode=fresh_initial_config`、验证起止日和 `validation_return_basis=peak_invested_roi`，两个代表点均可按该窗口载入回测复现。

## 连通域、规模与诊断

只有成功评价且原成本 `f > 1e-12` 的点属于正收益域。每次只允许一个勾选参数移动一个最小刻度；对角接触不连接。未勾选参数仍参与全局搜索，扩张时固定，不同固定值切片分别形成区域。

区域可以弯曲、不对称、存在孔洞，也可只有一个正点。成员收益无需相等，代表点无需为局部收益峰。不再要求对称半径、矩形、完整 `3^d` 邻域或等值平台。

成员数为主要排名指标，域占比为成员数除以该固定参数切片的合法组合总数。并列依次按最稳定点的稳定距离、域平均超额、最高超额和坐标字典序排名。各维范围仅为包围范围，其任意笛卡尔积组合不一定属于该域。

最大回撤、成交次数、买卖次数仍记录在成员及代表点上，作为诊断，不改变原成本正收益成员、代表点或域推荐资格。双倍佣金、最低佣金和滑点只作压力诊断，也不改变区域。

## 两个代表点

- **参数最稳定点**：勾选且可移动的参数按各自有效搜索范围归一化；用精确欧氏距离计算到最近内侧边界成员的距离，选距离最大者。成员只要有一个逐维方向超出本域，就是内侧边界；搜索范围边缘亦计入。边界点距离为 0。并列按自身原成本超额更高、坐标更小决定。
- **超额收益最高点**：域内原成本整个内部验证区间 `f` 最大的点；并列按稳定距离更大、坐标更小决定。

稳定距离衡量参数扰动容忍度，不是时间表现的波动率。两个点可以相同，此时显示双标记。单点域、无可移动维度时稳定距离为 0。默认载入、固定方案与动态方案使用排名第一片域的最稳定点。

距离计算采用 SciPy `cKDTree` 的精确查询并分块执行，不建立全体成员两两距离矩阵。

## 入口预算与完整扩张

保留 `auto`、`hierarchical`、`exhaustive`。`auto` 在合法组合不超过两项预算时完整枚举；显式完整枚举保留现有预算预检。分层模式默认训练预算 20,000 个唯一点，`validation_budget=100000` 表示入口探测预算。

训练保留粗网格和固定种子抽样，细化按多个高分起点轮转、逐维一步、由近及远探查，避免从全范围下界截取密集笛卡尔积。

入口名额一半优先给训练高分点，其余为固定种子的全域分层抽样；去重后补齐。入口集合在读取内部验证得分前确定。发现正点即向未计算的逐维合法邻点扩张；正点继续扩张，非正点阻断。优先清空扩张队列，再继续其余入口。多个入口遇到同一片域时合并，评价缓存只在同一决策、阶段和成本情景内复用。

**入口预算不是扩张硬上限。所有已发现正域必须探查至边界闭合，才正常结束。** 大片区域会超过入口预算；推荐域数量不会截断已发现域的计算。负点与零点必须实际完成评价，搜索范围外和不合法点无需回测。未知、失败和非有限结果不能用作负边界；失败点重试一次，仍失败则任务未完成，不生成正式完整推荐。

预算发现的区域完整，不代表找到了所有孤立区域。若要保证没有遗漏，需完整枚举全空间。

## 结果、档案与统计解释

每片域保存 `geometry=connected_lattice`、`connectivity=axis_one_tick`、成员数、域占比、收益统计、包围范围、`stable_point`、`peak_point`、成员集合哈希和归档引用。

- `complete=true`、`boundary_closed=true`：成员及外部合法边界已完成评价，该区域在给定范围内完整。
- `global_exhaustive=true`：整个合法参数空间已成功评价，不仅是当前区域完整。
- `coverage_status=discovered_components_closed`：已发现域闭合，其他孤立域可能未发现。
- `budget_overrun_count`：实际评价唯一点数超出入口名额的部分。
- `adaptive_validation_search=true`：后续评价坐标根据内部验证得分决定。

新分层模式记录 `seed_plan_hash`、`evaluation_set_hash`、`evaluation_trace_hash`，不再声称全部评价点事先冻结。其固定候选族内部 bootstrap 返回 `not_applicable`，不报告相应 p 值，也不会重建全部候选的逐日收益矩阵。完整枚举与旧模式继续使用各自适用的统计流程。历史固定／动态方案后续回测保持原时间隔离。

完整成员通过 `region_ids` 保存在压缩候选档案中，主结果仅含摘要和两个代表点。`recommended_params` 以及兼容字段 `center_params` 指向最稳定点。

## 展示与接口

推荐列表以整片参数域为一行，同时显示两个代表点、收益、成员数、闭合状态、搜索边界和诊断。两个载入入口各自复现其原成本完整验证窗口。

`GET /api/v1/results/{id}/landscape` 新增连通域视图：

- `view=members`：准确成员分页，首屏不抽样；使用 `region_id`、`offset`、`limit`。
- `view=slice`：指定 `x`、`y`，其他参数固定于 `anchor=stable|peak`。
- `view=projection`：所有高维成员按横纵坐标聚合，返回每个坐标的成员数与当前着色指标均值；投影坐标亦可分页。

`decision=current|fixed|adaptive` 和 `decision_index` 选择研究决策；`cost`、`fold` 只改变着色，区域及代表点始终按原成本全验证段确定。训练搜索分布沿用原接口。

精确切片使用真实坐标保留空洞，不填充矩形或压缩缺失刻度。投影重叠不代表高维参数能任意组合。图形分页明确显示已显示数量，未显示页不会插值。

`GET /api/v1/results/{id}/regions/{region_id}/export?decision=current&decision_index=0&format=csv|json` 导出全部成员。

## 执行资源与性能

沿用统一 CPU 配额、Numba 批量回放和工作集分块。邻接每点最多检查 `2d` 个方向，阶段间复用唯一点评价结果。分层模式不长期保留全部候选日收益矩阵。

`performance.timings` 增加训练、入口评价、边界扩张、连通分组、稳定距离及压力诊断耗时。进度报告已评价点、已发现／已闭合域、待评边界和预算超出量。

完整区域的实际耗时随域规模增长，不通过截断已发现区域换取完成状态。历史 v1 的峰、对称矩形、固定半宽及冻结候选集语义仅适用于其旧版本。

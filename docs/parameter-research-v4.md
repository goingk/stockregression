# 参数研究 v4：四维稳健 J 峰值

新版研究使用 `protocol_version=4`、`strategy_version=4`、`schema_version=3`，结果几何标识为 `geometry="robust_j"`。历史 v1、v2、v3 仍通过各自版本入口复现。旧六维受限策略与新四维自然持仓策略属于不同策略族，结果不宣称严格等价。

## 参数空间与执行账户

搜索轴顺序固定为：

```text
buy_step → sell_step → buy_shares → sell_shares
```

初始持仓 `P0` 属于研究上下文，必须大于零，不进入搜索空间。稳健 J 固定使用 `min_shares=0`、`max_shares=null`，允许自然持仓。普通回测和历史研究继续支持原持仓上下限。

股数是实际成交输入；比例只作结果派生：

```text
q_buy  = buy_shares / P0
q_sell = sell_shares / P0
```

每个轴只有一个权威采样宽度 `granularity`。网格点是整数刻度的 `low + i × step`；上下限分别向合法方向取整，上限不要求恰好落在步长上。间距以 0.01 个百分点、股数以 100 股为参数最小单位，研究细粒度必须是这些单位的正整数倍。四个轴之外不再接受 `step`，避免范围步长和细粒度双重定义。

## 收益率与持仓状态

中心原始收益采用现有研究口径：

```text
R = 网格收益率 - 独立买入持有账户收益率
网格收益率 = 净利润 / 峰值净投入
```

不增加固定资金池变量。买入持有基准继续使用独立账户。

持仓状态在初始化和每次实际持仓变化时更新，包含应收股份；不通过抽样后的净值曲线反推。结果记录实际最小／最大持仓、库存不足次数和 T+1 可卖不足次数。库存不足只在有效卖出信号发生时统计，同一连续信号的重复尝试只计一次；总持仓足够、仅 T+1 不可卖时单独记录，不混入库存不足。公司行动发行的应收股份参与经济持仓，实际成交继续遵守现有 T+1、停牌、涨跌停、整手和零股清仓规则。

## 目标函数

```text
J(x) = αR(x) + (1-α)μΩ(x) - βσ⁻Ω(x) - Cpos(x)

μΩ(x) = Σ w(x,y) R(y)

σ⁻Ω(x) = sqrt( Σ w(x,y) [min(0, R(y)-τ)]² )

Cpos(x) = γmax max(0, ηmax(x)-ηlimit)²
        + γmin max(0, ηfloor-ηmin(x))²
```

邻域是以中心为中心的固定边长超正方体，在整数刻度空间截取真实合法点。权重为整数索引距离上的高斯核：

```text
w_raw(x,y) = exp(-||x-y||² / (2σ²))
w(x,y)     = w_raw(x,y) / Σ w_raw(x,z)
```

边界只使用实际存在的合法邻点并重新归一化。固定轴不扩张，中心不向内部平移。直接实现与张量实现使用同一公式；张量路径把合法权重质量和观测掩码分开，零值缓冲区不能当作真实样本。

## 资格、峰值与平台

中心成为正式推荐候选必须满足：

1. 原始回测完成且收益、回撤、持仓、成交数据有效；
2. 训练期最大回撤不超过约束；
3. 成交数达到下限，并同时存在买入和卖出；
4. 实际最大持仓不超过 `eta_hard_cap`；设为 `null` 时关闭；
5. 邻域完整，`J > 0`；
6. 在一格联合邻域内完成峰值核验。

不使用 `R > tau` 作为候选前置过滤。持仓硬阈值只影响事后资格，不影响回测轨迹或实际买入。邻域中的低收益、高回撤、持仓超限和交易不足点仍以真实 `R` 参与邻域均值与下行风险，不能为了抬高分数而剔除。

峰值在“中心资格成立”的可行域上判断。每个合格中心与全部一格联合邻点比较；相等平台需要闭合整个连通平台，并检查平台所有出口。存在更高合格出口时不能认证为峰值。完整平坦域只输出坐标字典序最小的确定性代表，并标记 `platform_type="flat"`。Top-K 按平台代表去重，不因邻域重叠提前删除不同峰值。

排序依次为：

```text
J 降序 → 邻域均值降序 → 下行风险升序 → 持仓惩罚升序
→ 中心 R 降序 → 坐标字典序
```

回撤为零是有效值，不能转换为无穷或不合格。评分不完整、核验未闭合、邻域失败都不会产生自动执行参数。没有合格峰区时，历史固定与自适应回测仍保持暂停交易语义。

结果页的 **J 排名推荐**独立于上述执行资格：从已有完整 J 评分中按同一排序取前 `recommendation_count` 组，即“推荐参数个数”。即使全部 J 非正或全部候选未满足约束，也展示已有候选中的前 K 组，逐组标记约束原因并提供载入回测按钮。排序不再受 `top_candidates` 或二维热图抽样上限截断，也不局限于已核验峰区。

参数收益分布同时显示最高超额收益点与最高 J 点，包括参数、J、中心超额、邻域均值、下行风险、正收益比例、邻域点数和评分完整状态。超额相同时按四轴参数字典序选择确定代表。两个代表点均可载入回测。

## 搜索方法

默认策略是“可完整覆盖时穷举，否则改进分层搜索”。

| 方法 | 用途与决定 |
|---|---|
| 完整枚举 | 小空间默认方法，同时作为搜索基准。所有合法中心都由完整 J 场评分。 |
| Sobol 覆盖 + 多来源起点 + 局部细化 | 大空间默认。先覆盖采样，再从高 R、高 `R-Cpos`、空间覆盖三类来源等额选起点。 |
| 小生境差分进化 | 后续对照算法的第一优先级，当前版本未接入。需要离散映射、重复点控制、小生境尺度和邻域预算管理。 |
| 多种群粒子群 | 后续扩展，优先级低于小生境差分。离散位置、种群停滞和合并成本更高。 |

当前默认四维刻度仍可能产生 90,440,100 个组合，因此不构造默认全空间张量。`auto` 在合法组合数不超过训练预算且预计工作内存不超过上限时选择穷举；否则选择分层搜索。显式 `exhaustive` 不满足预算或内存条件时返回明确预检错误，不静默降级。

分层流程：

1. 生成角点、中点和现有统计启发式种子；
2. 使用独立可复现随机流生成优先为 `2^m` 的 Sobol 批次，再映射、去重并截取到预算；
3. 起点数为 `min(start_max, max(start_min, starts_per_candidate × K))`，再受实际可用中心数限制；
4. 各起点轮转使用预算，先做一格、两格局部搜索；停滞后再按倍率尝试更大步长；
5. 每轴大步长不超过该轴跨度的 `max_stride_fraction`；
6. 默认预留邻域评价预算的 `validation_reserve_fraction` 给最终峰值核验；
7. 强制精算完整一格联合邻域；发现更高 `J` 时沿上升方向继续搜索。
8. 搜索结束后补齐最高超额收益点的实际邻域，并确保有足够的完整评分供 J 排名；新补算邻点成为最高收益点时，继续补齐新代表的邻域。此阶段按新增唯一回测点单独记录为 `reporting_evaluations`，不占用搜索与峰值核验预算。失败点仍明确记为缺失，不填零。

全局覆盖距离使用归一化坐标；邻域与高斯权重使用整数刻度距离，两者不能混用。Sobol 截取后的任意点数不宣称保持完整平衡性质。

预算按实际新增唯一回测点计数。缓存命中的重复请求不再次收费；评估失败仍占用已经发生的预算。费用压力、Bootstrap 和最终回放分别统计。`r=1` 且四个轴活动时，单中心 J 最多需要 81 个原始点；核验全部相邻中心 J 的支持集最多 625 个原始点，等值平台闭合可能继续增加。

## 训练窗口与随机性

每次决策只使用当时已经收盘的数据。评估日之前最后一个收盘价记为锚价，在向前 `training_min_days` 至 `training_max_days` 个交易日中寻找：当日最低价低于锚价且最高价高于锚价的同价日。

- 取距离评估日最远的一个作为训练起点。
- 没有匹配日时回退到 `training_max_days`。
- 少于 `training_min_days` 时返回历史不足，不授予正式推荐。
- 数据准备、预检、窗口选择和结果说明共享同一个 `TrainingWindowPolicy`。

固定方案在样本外评估前锁定参数；自适应方案每隔 `rebalance_days` 个交易日按当时信息重选。固定和自适应使用连续账本，换参不重置资金、持仓或收益。追加未来行情或延长评估区间不能改变既有决策日的参数。

根种子、算法版本、决策日期和用途稳定派生独立随机流。采样、搜索与 Bootstrap 分开，不依赖线程顺序、Python 随机哈希或未来行情版本。相同种子下改变线程数和批大小不改变抽样计划。

## 缓存与结果

缓存分三层：

1. 原始回测：参数、历史范围、引擎版本、成交和费用配置；
2. 评分：原始结果标识、轴定义、邻域和 J 参数；
3. 统计：参与对象、日收益序列和抽样参数。

修改 `alpha`、`beta` 等评分参数可以复用原始回测；修改费用必须重新计算原始结果；页面轮询间隔变化不使科学结果失效。

每个推荐峰区和候选行至少记录：

- 四维坐标、股数、`q_buy`、`q_sell`；
- `J`、中心 `R`、邻域均值、下行风险、上界和下界持仓惩罚；
- 实际最小／最大持仓、库存不足次数、T+1 不可卖次数、邻域最差上限；
- 邻域点数、正收益比例、安全垫达标比例；
- `score_complete`、`local_peak_verified`、`global_exhaustive`、`coverage_status`、平台类型和平台大小；
- 训练唯一评价点、邻域唯一评价点、缓存命中、失败和取消状态；
- 实际训练窗口、费用压力、完整配置快照和数据版本。

“评分完整”“局部峰值已核验”“全局空间已覆盖”是三个独立状态。分层搜索的峰区认证只声明已核验的局部峰区，并报告覆盖不足；J 排名同时保留其他完整评分的候选。不能用单个 `complete` 字段混淆。

历史结果打开参数分布时，如果最高超额收益点的邻域尚未完整计算，会使用结果锁定的数据版本和原训练时段补算缺失邻点，并缓存展示叠加数据；原始结果和候选档案保持不变。原版本或训练时段不可用时，页面显示明确的补算失败原因。

结果中的 `recommended_p_min/max` 是训练期实际观察范围，不自动成为回测护栏。加载新版结果时继续使用自然持仓；用户加入持仓限制后形成新的回放配置并重新计算。

## 兼容与测试边界

- 策略 v1 的固定矩形邻域、v2 的正收益连通域和 v3 的超正方体平均超额继续保留历史语义。
- 新版 v4 的完整 J 张量结果与直接求和实现要求绝对误差不超过 `1e-12`。
- 小空间完整枚举用于验证稀疏搜索的召回、峰区定义和预算状态。
- 搜索方法比较必须使用同一个四维空间、同一个 J 和相同原始回测成本模型。小生境差分和多种群粒子群尚无本项目同预算实测，不能据此宣称绝对优劣。
- `docs/robust-search-benchmark.md` 记录固定样本的搜索层基准；真实行情的最终验收仍需按相同数据版本复跑。

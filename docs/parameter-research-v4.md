# 参数研究 v4：等比网格最大正超额邻域

`protocol_version=4` 将参数研究限定为等比网格，五个研究维度为 `grid_step`、`sell_shares`、`buy_shares`、`min_shares`、`max_shares`。初始持股固定，不参与搜索；最高持股可独立设为“搜索有限上限”或“固定不限”。

## 固定单位

- 网格间距以 0.1 个百分点为最小单位，接口数值为 `0.001`。
- 所有数量参数以 100 股／份为最小单位。
- 搜索、去重、平台与邻域计算使用整数刻度；范围端点不对齐单位时返回配置错误。
- 训练阶段可以采用较粗的分层网格，正式邻域验证始终恢复到上述最小单位。

## 目标与时间边界

每个决策日只读取当时已收盘的数据，取最近 504 个交易日。前 252 日用于训练搜索，后 252 日用于内部验证。

```text
f(x) = 网格峰值本金收益率(x) - 独立全仓持有收益率
```

验证收益按连续账户的整段资产和实际补款计算，四段 63 日窗口仅用于表现和风险诊断。原成本决定峰值、资格和排名；双倍佣金、最低佣金及滑点只作诊断。可显式选择零滑点研究。

## 搜索与冻结

研究支持 `auto`、`hierarchical` 和 `exhaustive`。`auto` 在合法组合数不超过训练与验证预算时完整枚举，否则使用分层搜索。默认每决策日训练预算 20,000 个唯一点、验证预算 100,000 个唯一点。

分层训练由全范围粗网格、固定种子分层抽样和多区域细化组成。训练结束后先冻结验证点集合与哈希，再读取后 252 日收益；验证结果不能追加集合外搜索点。

## 峰值与邻域

峰值比较参数空间中的全部联合相邻点，最多为 `3^d-1` 个。等值连通平台必须检查全部外边界；边界更高或缺少评价时不构成已验证峰，平台只输出一个代表点。

邻域为以峰值为中心、各维独立宽度的对称长方体：

```text
B(x,r) = { y : |y_i - x_i| <= r_i * unit_i }
```

默认模式为 `max_volume`：在冻结验证域内搜索体积最大的完全正收益邻域。固定模式 `fixed_mean` 使用各维指定半宽并按邻域平均 `f` 排名。两种模式都要求中心及邻域全部合法点完成原成本评价且 `f > 1e-12`。

最大邻域的归一化体积按各维宽度除以有效搜索范围宽度后连乘。固定维度不参与体积。边界无法形成完整对称邻域时只保留诊断，不授予正式推荐。

## 结果解释

- `recommendation_status=qualified` 表示至少有一个完整正超额邻域。
- `global_exhaustive=true` 表示合法参数域已完整枚举；分层结果仅代表预算内发现的前 n 名。
- `maximum_search_complete=false` 表示最大性尚未确认。
- 双倍成本结果不改变原成本资格。
- 没有合格邻域时正式推荐为空，相对最佳参数只作诊断。

结果保存推荐区域、整数半径、各维边界、组合数、均值／最低／峰值超额收益、完整性和压力诊断。二维分布接口支持按决策、训练／验证、成本、窗口、区域筛选和分页。

v4候选归档保存在结果旁的压缩工件中，主结果 JSON 只保留引用和摘要；读取历史结果时由存储层透明恢复候选列表。

# 统计驱动参数研究协议 v3

> 新研究默认使用 `protocol_version=4`。v4 固定等比网格，采用 0.1 个百分点与 100 股／份的最小单位，并默认寻找最大正超额收益邻域。本文保留为 v3 历史结果与兼容接口说明；新方法见[参数研究 v4](parameter-research-v4.md)。

## 时间、账户与收益口径

表单的开始、结束日期指定样本外评估区间。数据准备向前读取 504 个真实交易日并锁定一份不可变快照。固定方案在评估开始前选择一次，自适应方案每 63 个交易日重选；后续决策只使用当时已经收盘的数据。

新配置使用 `schema_version=3`。最高持股可以留空，表示不设数量上限；填写时只限制数量。固定可用现金预算已经删除。所有网格从期初零现金开始，成功买入所需金额超过现有现金时只补足差额。拒单、撤单和暂停不补款；卖出回款、已到账股息和账户内资金优先复用。

收益同时保留两个口径：

```text
I(t) = 初始持股估值 + 截至 t 的累计外部补款
A(t) = 现金 + 持仓市值 + 应收权益
P(t) = A(t) - I(t)
I_peak = max I(t)

峰值本金收益率 = P(T) / I_peak
收益率曲线 = P(t) / I_peak
```

尚未发生的补款不能被当作早期亏损。资金流按到达时账户价值单位化，日收益、年化、夏普、回撤和 Calmar 使用资金流调整后的单位净值。分窗统计只重设统计起点，不重新开户；窗口本金为窗口开始资产加窗口内补款。

## 候选生成

完整决策窗口为 504 日：前 252 日用于统计画像、中心形成和局部搜索，后 252 日分为四个连续 63 日验证窗。

统计画像只读取候选生成段，并使用 `preclose` 处理公司行动：

- 日内向上、向下波动和真实波幅的 25%、50%、75% 分位。
- 对数收盘价趋势强度。
- 下跌交易日后固定 5 个交易日的修复收益中位数；观察不得越过生成段终点。
- 按实际费率和滑点估计的往返成本，以及两个最小价格档位。

移动网格分别由向下和向上波动形成买入、卖出步长；等差和等比网格由真实波幅形成间距中心。中心不得低于“双向往返成本与两个价格档位中较大者”，并向用户搜索刻度取整。搜索范围是硬边界，系统不会自动扩大范围。初始持股由用户决定，行情统计不替用户推断可承受投入。

每个统计中心在各有效维度取中心及正负一个搜索步长，组成局部笛卡尔网格。默认唯一组合预算为 3000，最多 5000。提交时先计算实际数量，超过预算返回 `SEARCH_BUDGET_EXCEEDED`，不截断成另一种搜索方法。

生成段先保留每个统计中心附近表现最佳的合法点，再按“训练段相对全仓超额收益 − 资金流调整回撤”补足最多 10 个中心。补充中心之间至少相隔两个搜索刻度。原始配置作为独立对照，不自动获得推荐资格。

以上中心规则是可复现的工程假设，不解释为未来收益或理论最优参数。

## 冻结邻域与推荐资格

进入验证前冻结中心、候选编号和邻域。每个中心包含：

- 各有效维度正负一步的单参数扰动。
- 任意两个有效维度同时正负一步的联合扰动。

超出搜索边界的组合不计算，并记录边界裁剪；计算失败、取消或缺失的邻点不能被删除后重新提高通过率。所有维度固定时显示“无法评价邻域稳健性”。

验证段超额收益为网格峰值本金收益率减同期独立全仓持有收益率。默认推荐门槛如下：

1. 中心超额收益在原始成本和双倍佣金／最低佣金／滑点情景下均为正。
2. 至少 80% 的有效邻点超额收益为正。
3. 邻点超额收益第 25 百分位为正。
4. 中心满足最大回撤、最少成交和买卖双向约束。
5. 邻域、双成本和四个验证窗全部完成，并具备完整 504 日历史。

正超额比例和邻域分位数不包含中心自身。合格中心依次按“两种成本中较差的邻域第 25 百分位”“四窗超额收益的中位数减半四分位距”“较低回撤”“较低峰值本金”和候选编号排序。

中心超额为正但不足一半邻点为正时标为“疑似收益孤岛”。这表示该结果依赖孤立参数点，不直接把该点断言为噪声。没有合格参数时返回“暂无合格推荐”，相对最佳只保留为研究对照。固定方案首期不通过时暂停网格交易；自适应方案在任一次不通过时撤销待执行订单，保留持仓、现金和公司行动，下一次通过后恢复。

## 统计证据

主基准是独立 1000 股／份全仓持有账户，公司行动和股息留在账户内。保留配对 stationary block bootstrap 与家族校正：默认 10000 次，平均块长 20 日，并报告 10／40 日敏感性。

检验使用资金流调整后的日收益，回答的是时间加权收益优势；热力图默认显示峰值本金超额收益。两者不能互相替代。

完整冻结候选族进入内部家族检验，并标记 `internal_validation_used_for_selection`、`independent_oos=false`。末 126 日继续使用固定和自适应流程实际连续样本外轨迹。稳健性通过与非零统计优势分别展示，80% 邻域门槛不取代显著性检验。

## 参数收益分布

结果页提供二维参数切片热力图，默认横轴为买入间距、纵轴为卖出间距，也可切换为任意两个有效参数；其余参数固定于选中中心。训练搜索和内部验证分开读取。支持决策日期、成本情景、验证窗口及超额／网格收益切换。未计算组合保持空白，不插值。


默认 API 返回研究摘要和曲线，完整候选、训练组合和日收益矩阵保存在完整结果及显式导出中。热力图通过独立接口按需读取，不受候选表展示上限影响。

## 数据不足与执行边界

- 168～503 日历史仍可做探索性相对比较，但不授予正式推荐资格。
- 少于 168 日只显示样本内相对排名，不作显著性声明。
- 分钟覆盖不足时披露降级；估值、价格或公司行动硬错误阻止计算。
- 换参不补充现金，不重建持仓，不强制清仓。已有持仓超出新边界时只影响后续正常卖出。
- 旧结果按原口径展示；旧配置经转换入口生成 v3 草稿，不覆盖原记录。

## 复现与验收

候选账户在 Numba 中独立并行，账户内部严格按时间执行，生产回测与研究批量共用成交内核。结果记录数据版本、协议阈值、搜索预算、统计中心、候选邻域、双成本状态、资金流水和计算量。

验收要求是资金可对账、研究可复现、历史与未来数据隔离成立、邻域结论与热力图逐项一致。真实验收不以必须找到盈利参数作为通过条件。

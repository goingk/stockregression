# 科学参数研究协议 v2

## 时间与结果的含义

表单的开始、结束日期指定**样本外评估区间**。数据准备会向开始日前补读 504 个真实交易日，另保留估值所需的前收盘。计算锁定同一份不可变数据快照。

每个历史决策只读取决策收盘时已经存在的数据，随后从下一交易日执行。固定方案在评估开始前选择一次，整个评估期保持参数；自适应方案每 63 个交易日重选。两者的现金、持仓、交易限制和公司行动连续处理。

研究结束时另外输出截至最新收盘的固定参数建议。把这组最新参数应用到此前历史属于**样本内回看**；它不能继承历史固定方案或自适应流程的样本外成绩。配置、结果和导出保留选参截止日。

## 候选生成与评分

完整的决策窗口为 504 日：前 252 日用于 Optuna TPE 候选生成，后 252 日分为四个连续的 63 日验证窗。默认每个决策点 1000 次基础试验。批量生成和反馈采用固定顺序；种子只由请求种子和决策日期派生，不使用评估终点或快照版本作为随机输入。

初始股数和现金预算固定，候选仅包含当前网格模式的有效步长、每笔买卖数量和仓位边界。原始配置作为对照。每个可选择中心的各有效维度按正负一步生成邻域，连续范围未给步长时取范围宽度的 5%。所有邻域在读取验证表现前冻结。

每个候选从相同初始账户连续回放整个 504 日窗口。分窗时只计量收益、成交与回撤，不重新开户或清仓。回撤来自原始分钟／日线成交路径，日收益矩阵只用于收益统计和重采样。

每窗定义：

```
年化收益 = exp(sum(log(1 + 日收益)) × 252 / 窗口交易日数) - 1
U = 年化收益 - 最大回撤
跨窗分数 R = median(U) - 0.5 × IQR(U)
成本稳健分 = min(原始成本 R, 加倍成本 R)
最终选择分 = 参数中心及其邻域成本稳健分的第 25 百分位
```

加倍情景包括券商佣金、最低佣金及滑点；历史法定税费仍按已有日期规则计算。四窗稳定性、成本压力和参数邻域均用于降低单次行情或尖锐峰值对排名的影响。

默认约束为最大回撤不超过 20%，验证段至少 10 笔成交且包含买卖双向。合格中心优先，再按选择分、回撤、换手、候选编号稳定排序。全部不合格时仍返回相对最佳，逐项说明原因。评分系数属于预先指定的工程偏好，不能解释为最优金融理论参数。

## 证据与不确定性

同资金、同初始持股的被动持有是主要比较基准。现有独立全仓持有和定投继续作辅助比较。

主末段检验截取固定／自适应／被动账户实际连续路径的最后 126 个交易日。采用配对 stationary block bootstrap，所有流程使用相同日期索引，以保留时间相关和流程之间的相关性。默认 10000 次，平均块长 20 日，并报告 10／40 日敏感性。

候选族或预先声明流程族的收益优势检验采用 White Reality Check 类型的中心化最大统计量，报告家族校正 p 值及同时置信下界。检验对象为日对数收益相对基准的差，综合风险评分另行展示。p 值不是获利概率；重采样结论受弱相关、局部稳定性及有限历史样本的限制。

当前建议的检验涵盖本次冻结的全部中心和邻域候选，复用原成本的验证日收益矩阵。由于这些验证窗已用于参数排名，结果标为 `internal_validation_used_for_selection`、`independent_oos=false`，仅是内部诊断。末 126 日另对事先声明的固定／自适应两条实际样本外流程做家族检验，当前建议不参与这项检验。两类统计不会互相冒用。

本地审计记录协议、范围、种子、数据版本及验证日期的重叠。更换种子、参数或快照不会使同段历史重新变成未使用数据。程序隔离不能证明研究者从未看过行情，审计不会作出该声明。

## 数据不足与执行边界

- 前置历史为 168～503 日时，用前半生成候选、后半分四窗验证，明确显示不足 504 日。
- 前置历史少于 168 日时，返回样本内相对排名，不作显著性声明。
- 没有可计算历史时显示原始配置及无法比较的原因。
- 分钟覆盖不够时披露实际降级口径及较弱证据；估值、价格或公司行动硬错误阻止计算。
- 换参不补充现金、不重建持仓，不因规则变化虚构强制成交。已有仓位超出新边界时继续受正常交易信号、现金、可卖股数和涨跌停限制。
- 更换参数时撤销旧规则的待成交意图，仅用前收盘信息重建；下一根真实行情开盘成交。

## 数值实现与复现

候选账户在 Numba 中独立并行，每个账户内部按时间顺序执行，共用生产成交逻辑。每日收益、分窗精确回撤和成交摘要采用精简输出；最终方案保留完整成交、拒单及每日曲线。

重采样把同一批日期抽样转换为计数权重矩阵，用矩阵乘法同时求出全部候选或流程的统计量，分块控制内存。候选、邻域、双成本情景与真实计算量分别记录。取消时保留已经完成的研究记录，未完成压力情景不作合格证据。

默认 API 只传页面所需的候选摘要、每日曲线和检验结果；完整候选、试验及成本矩阵仍保存在结果文件和显式完整导出中。页面的候选展示上限不会截断实际验证或多重检验候选族。

真实验收标的固定为 **159611.SZ**。验收记录包含锁定快照、账户、日期、搜索范围、种子、样本外表现、前缀不变性和计算一致性，见配套验收报告。

## 研究依据

- [Bailey 等：The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：多次试验与回测选择偏差。
- [嵌套验证方法](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)：参数选择和流程评价的职责分离。
- [White：A Reality Check for Data Snooping](https://onlinelibrary.wiley.com/doi/pdf/10.1111/1468-0262.00152)：考虑搜索候选族的收益优势检验。
- [Politis 与 Romano：The Stationary Bootstrap](https://www.tandfonline.com/doi/abs/10.1080/01621459.1994.10476870)：有时间依赖的配对块重采样。

上述文献支持验证和统计方法；本项目具体窗口长度、评分权重及账户接口是显式版本化的工程约定。
